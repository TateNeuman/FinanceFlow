# FinanceFlow

## Live Demo

[Try FinanceFlow](https://finance-flow-mocha-eight.vercel.app)

FinanceFlow is available online. Create an account to explore the dashboard, manage transactions, track budgets, and set savings goals.

FinanceFlow is a personal finance management web application designed to make tracking and managing money easier. It provides a clean, modern dashboard where users can organize their finances, monitor spending, and work toward their financial goals.

The goal of this project was to create an easy-to-use application that brings important financial information together in one place.

## Features

- **Dashboard:** View income, expenses, account balance, and financial insights.
- **Transactions:** Add, edit, delete, and organize financial transactions.
- **Analytics:** Track spending habits and visualize financial activity through charts.
- **Budgets:** Set monthly spending limits and monitor progress.
- **Savings Goals:** Create financial goals, add savings contributions, and track progress.
- **Recurring Bills:** Manage subscriptions, recurring expenses, and recurring income.
- **Reports & Import:** View financial summaries and import or export transaction data using CSV files.
- **Cloud Storage:** Store and manage financial information using Supabase.

## Built With

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- CSS

## About the Project

FinanceFlow was developed as a personal project to gain more hands-on experience with web development, database management, and building a complete application.

Throughout development, I focused on creating a user-friendly interface, connecting the application to a cloud database, and making sure the different financial tools worked together.

This project helped me improve my skills in React, TypeScript, SQL, and troubleshooting issues throughout the development process.
